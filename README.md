# Victoria Sharapova portfolio

English-language portfolio site in progress. The source of truth for copy and artwork is Victoria's Figma file; this repository intentionally does not contain placeholder projects or substitute images.

## Local development

```sh
npm install
npm run dev
```

## Deployment

Vercel can import this repository as a Next.js project. Do not publish until the Figma artwork, responsive layouts, and visual checks are complete.
